# 🖼️ Before-and-After Image Slider

A lightweight, responsive, and interactive "before-and-after" image comparison slider. Built with pure HTML, CSS, and vanilla JavaScript—no external libraries required!

## ✨ Features
* **Zero Dependencies:** Pure vanilla JavaScript and CSS (`clip-path`).
* **Fully Responsive:** Adapts to any screen size or container width.
* **Touch & Mouse Support:** Works smoothly on desktop and mobile devices.
* **Embeddable:** Perfect for embedding into Canva presentations, Canva websites, Notion, or any other platform that supports iFrames.

## 🛠️ How to Use

### Use it on your own website
1. Clone or download this repository.
2. Replace `before.jpg` and `after.jpg` with your own images in the root folder.
3. Open `index.html` in any web browser.

### Embed it in Canva
You can add this interactive slider to your Canva Presentations or Canva Websites:
1. Ensure this repository is published via **GitHub Pages**.
2. Open your Canva design.
3. Go to **Apps** on the left sidebar and search for **Embed**.
4. Paste your GitHub Pages live URL into the Embed app.
5. Resize the bounding box to fit your slide. The slider will be interactive in "Present" mode or on a published Canva Website!
